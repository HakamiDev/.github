## What we do

- **AI experimentation:** Explore AI agents, models, and emerging technologies through hands-on projects.
- **Practical tools:** Turn useful ideas into software people can try.
- **Research and development:** Test assumptions, evaluate solutions, and document what works and what doesn't.
- **Open knowledge:** Share implementations, technical findings, and lessons learned.

## Featured project

### [ProjectForge](https://github.com/HakamiDev/ProjectForge)

**A structured workspace for AI-agent teams.**

ProjectForge helps turn an ordinary folder into an organized workspace for AI-assisted projects. It brings together shared task boards, defined agent roles, quality checks, decision tracking, audit logs, reusable templates, performance reporting, and a local management interface.

[View the repository and setup instructions](https://github.com/HakamiDev/ProjectForge)

> Check the project's README for supported environments, current release status, and known limitations.

## How we work

**Build** useful experiments. **Test** them against real needs. **Refine** them based on evidence. **Share** tools and lessons openly.
